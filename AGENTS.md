# Guía del proyecto

- Sitio estático en HTML y CSS, sin proceso de compilación documentado. La entrada principal es [index.html](index.html); la hoja de estilos es [src/style.css](src/style.css) y los recursos están en [src/img/](src/img/).
- Conserva el idioma español, el texto existente y los destinos de navegación. Revisa [README.md](README.md) para el contexto del sitio.
- Mantén los cambios acordes con la estructura actual. No agregues dependencias ni herramientas de compilación para cambios simples de presentación.
- Valida los cambios visuales abriendo `index.html` en un navegador y comprobando escritorio y móvil; no hay comandos de build o test documentados.
